## Level 5 — Interactive Sales Dashboard

### Project Overview

Built an interactive Excel sales performance dashboard to analyse revenue, units sold, regional performance, product performance, salesperson performance, and monthly sales trends across 2025 and 2026.

### Skills Demonstrated

- Data validation and quality checks
- Excel Tables
- PivotTables
- PivotCharts
- KPI cards
- Revenue and unit analysis
- Monthly and yearly trend analysis
- Interactive slicers
- Multiple PivotTable report connections
- Multi-filter dashboard analysis
- Dashboard layout and formatting
- Dashboard testing and quality assurance

### Dashboard KPIs

- Total Revenue: £440,679
- Total Units Sold: 1,147
- Top Region: South — £121,083
- Top Product: Laptop — £152,640
- Top Salesperson: David — £83,122

### Dashboard Visuals

- Monthly Revenue Trend — 2025 vs 2026
- Revenue by Region
- Revenue by Salesperson

### Interactive Filters

The dashboard includes slicers for Region, Product, and Year. The slicers are connected across multiple PivotTables, allowing users to analyse different combinations dynamically.

### Key Analytical Insight

Interactive filtering showed that the South region generated £37,962 in revenue from 156 units in 2026. Printer was the top-performing product for this selection, generating £21,398 from 48 units.
